Данный сайт, разработанный с использованием языка программирования JavaScript, предоставляет возможность навигации по корпусу УрФУ на Тургенева, 4. На сайте предоставлены планы этажей корпуса с расположением аудиторий и других необходимых мест корпуса, а также возможность построить навигацию между двумя искомыми местами через поиск. Для удобства пользования международными студентами сайт выполнен не только на русском, но также на английском и китайском языках.
